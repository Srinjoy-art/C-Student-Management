# Student Management System in C

This is a beginner-level C project I built to practise programming concepts through a simple student record management system.

The program uses a menu to let users manage student information from the terminal. Building it helped me understand how different C concepts can work together in a single program.

## Features

- Add a new student record
- Display all student records
- Search for a student
- Update student details
- Delete a student record
- Exit the program through the menu

## Built With

- C Programming Language
- Standard C Library

## How to Run

You need a C compiler such as GCC.

**1. Compile the program**

```bash
gcc Student_Management_System.c -o student
```

**2. Run on Windows**

```bash
.\student.exe
```

On Linux or macOS:

```bash
./student
```

If your source file has a different name, replace `Student_Management_System.c` with its actual filename.

- Arrays

- Searching and updating records
- Menu-driven programming
